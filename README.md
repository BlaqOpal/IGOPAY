Microfinance-Banking-Security
This project is a secure and feature-rich banking website built with Django, designed to enhance the security of microfinance internet mobile banking through context-aware session expiration and adaptive re-authentication mechanisms. It provides essential banking functionalities while protecting users from threats like session hijacking and unauthorized access, tailored for underserved communities with a focus on usability and scalability.
Site Components:

Create Bank Account with Account Numbers, PIN Numbers, etc.
Advanced KYC Registrations and Verification
Send Money/Payments to Other Users using Account Number
Accept Payments from Friends, Family, or Anyone
Create New or Link Existing Virtual Credit/Debit Cards
Send Money to Credit/Debit Card for Online Purchases or Payments
Withdraw Money from Credit/Debit Card to Account Balance
Advanced User Authentication (Login, Logout, Register) with context-aware security
Delete Linked Credit Cards and Transfer Remaining Funds to Account Balance
Notification System
Tracking of Transaction History
Implement Context-Aware Session Expiration to automatically terminate inactive sessions (e.g., after 15 minutes)
Integrate Adaptive Re-Authentication with OTP or password prompts triggered by risk factors (e.g., IP change, device switch)
Host the Application on Railway Hosting

Tech Stack:

Python
Django
Ajax
